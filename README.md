# Frit-Neoforged-Spawners — Resourcepack

Official resourcepack for **Frit-Neoforged-Spawners**, a Minecraft 1.21.1 NeoForge spawner mod.

## Features

- Custom designs for Coal, Copper, Iron, Gold and Diamond Spawners
- Dark, industrial-style inventory interface
- Material-themed spawner icons
- Unified visual design
- Compatible with Minecraft 1.21.1

## Installation

### Singleplayer
1. Download the latest resourcepack ZIP from [Releases](https://github.com/Nicofrit/Resourcepack/releases).
2. Place the ZIP in your Minecraft `resourcepacks` folder.
3. Open Minecraft → Options → Resource Packs.
4. Enable the resourcepack.

### Multiplayer Servers
Server owners can distribute the resourcepack automatically by providing its public download URL in `server.properties`.

```properties
resource-pack=https://github.com/Nicofrit/Resourcepack/releases/download/Resourcepack/Frit-Neoforged-Spawners_Resourcepack.zip
require-resource-pack=true
```

Make sure the referenced ZIP has been uploaded to the release before using this URL.

## Important Notes

The resourcepack changes the appearance of the standard six-row chest interface. This means other inventories using the same interface may also receive the new design.

The resourcepack contains visual assets only. The spawner mechanics, storage pages, commands and automation are provided by the mod itself.

## Mod Features

Frit-Neoforged-Spawners is designed to support:

- Five resource-producing spawner types
- Up to 20,000 stacked spawners per block
- Up to 100 inventory pages
- Create automation
- Redstone controls
- Personal spawner management

These gameplay features require the mod and are not added by the resourcepack.
